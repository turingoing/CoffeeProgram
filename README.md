# Caldi Coffee 微信小程序

## 项目简介
本项目是一款为 Caldi Coffee 量身定制的微信小程序点单系统。它为用户提供便捷的咖啡在线订购服务，支持门店自提和外卖配送。项目集成了完整的商品展示、复杂的规格选择、购物车、订单管理、会员积分、优惠券、发票开具以及个人中心等功能，旨在提供极致的移动端消费体验。

## 技术栈
- **核心框架**：微信小程序原生框架
- **UI 组件库**：Vant Weapp、TDesign Miniprogram
- **状态管理**：全局数据 (globalData) + 本地缓存 (localStorage)
- **工具库**：CryptoJS (加密)、dayjs (时间处理)
- **网络请求**：原生 wx.request 封装

## 核心功能
- **智能点单**：支持多维度规格选择（杯型、温度、甜度等），动态计算价格。
- **门店管理**：基于地理位置推荐最近门店，支持切换门店。
- **会员系统**：完善的积分积累与兑换机制，支持优惠券领取与使用。
- **支付结算**：集成微信支付，支持余额充值及消费记录查询。
- **开票服务**：在线申请电子发票，管理开票记录。

## 技术难点与亮点

### 1. 复杂 SKU 与多规格联动逻辑
在咖啡点单场景中，单一商品往往对应多种规格组合（如：大杯/中杯、热/冰、不加糖/半糖等）。项目实现了复杂的 SKU 映射算法：
- **动态价格计算**：根据用户选择的不同规格实时计算最终售价。
- **库存校验**：在选择规格时实时校验对应 SKU 的库存状态，对缺货组合进行置灰处理。
- **规格持久化**：记录用户对特定商品的偏好，提升复购体验。

### 2. 全局购物车状态一致性
由于点单流程跨越了首页、分类页、详情页和结算页，且存在分包加载，确保购物车数据的一致性是一大挑战：
- **多级缓存机制**：结合 `globalData` 的响应式数据和 `localStorage` 的持久化存储，确保用户在关闭小程序后购物车依然保留。
- **跨页面通信**：利用事件总线或全局回调函数，在详情页加入购物车后，实时更新底部 TabBar 的红点提示及购物车浮层数据。

### 3. 自定义 TabBar 与分包架构优化
随着功能不断增加，项目采用了分包加载策略以突破微信小程序 2MB 的主包限制：
- **分包策略**：将用户中心、订单详情、开票系统等非核心路径功能移至分包，显著提升首屏加载速度。
- **自定义 TabBar**：解决了分包页面切换时 TabBar 闪烁及状态同步问题，提供了更原生、更流畅的导航体验。

### 4. 隐私合规与安全防护
- **隐私协议拦截**：响应微信最新隐私合规要求，开发了 `privacyPopup` 组件，在用户未授权前拦截敏感 API 调用。
- **安全加固**：关键业务请求采用 `CryptoJS` 进行 HMAC-SHA256 签名校验，防止请求被篡改，确保交易安全。

### 5. 地理位置与地图服务集成
- **精准定位**：集成微信地理位置 API，实现自动定位周边门店及地址逆地址解析（Reverse Geocoding）。
- **配送范围校验**：在用户选择外卖地址时，动态计算门店与地址间的距离，确保在有效配送范围内。
